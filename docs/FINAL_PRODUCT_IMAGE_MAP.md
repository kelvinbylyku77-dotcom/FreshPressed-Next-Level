# Fresh Pressed — Final Product Image Map

This pass prioritizes **accuracy over forced uniqueness**.

## Rules used
1. Use an exact product still when the product identity is confirmed.
2. Use a strong branded representative image only when it clearly fits the category.
3. Keep the current image when the available replacement could mislabel the product.
4. Do not use reel frames when a clean still is available.
5. Keep `representative: true` on any image that is not confirmed as the exact SKU.
